# LeetCode 基础补强计划（C++ · 入门起步 · 每天约 1 小时）

> 目标不是「刷完多少题」，而是**建立知识点 → 题型 → 模板的条件反射**。
> 本计划共 **137 题**：必做 **120 题**，可选 **17 题**；必做部分约需 **118 个学习日**。

## 一、为什么是这个题单

| 方案 | 题量 | 适合谁 | 对你的问题 |
| --- | --- | --- | --- |
| 力扣热门 100 | 100 | 有基础、临时抱佛脚 | 同知识点题目分散，刷完记不住规律 |
| 剑指 Offer | 75 | 国内面试 | 偏面试套路，基础体系不全 |
| **NeetCode 150 精简版（本计划）** | 137 | **入门到进阶、想补基础** | **按知识点分组，同类题连刷，规律自己浮现** |

关键差别：热门榜按「出现频率」排序，第一题是哈希、第二题是链表、第三题是 DP；
而按知识点连刷时，你在第 3 题就会开始想「这题和上一题只差一个条件」，**这才是基础长出来的方式**。

## 二、总体节奏

- **周期**：约 25-26 周（6 个月左右，含缓冲）
- **每周**：6 天新题 + 1 天纯复习（复习日不碰新题）

- **复习日做什么**：把本周题目里「看了解析才会」的全部重做一遍，不看题解

### 阶段 5 · 动态规划（你的第二个坎）

- **覆盖**：一维 DP → 二维 DP

## 五、攻克递归与 DP 的专门方法

这两块是入门者最容易卡死的地方，卡死的原因几乎都是同一个：**想直接写出最优解**。

### 递归四步法

1. **写函数签名 + 一句话含义**，先不写函数体。例：`int depth(TreeNode* root)` = 以 root 为根的子树高度。
2. **写终止条件**（空节点返回什么？叶子返回什么？）
3. **假设子问题已经解决**，只写「当前这一层」怎么用子结果。不要跟进递归里。
4. **补一行返回值**，然后直接交，把用例在脑子里跑一遍。

> 反例：`if (root == nullptr) return 0;` 这行几乎所有树题都要写，先写它，手就不会抖。

### DP 三段式（务必按顺序，不许跳）

1. **暴力递归**：`dfs(i)` 表示「从第 i 个位置开始的最优解」，先写不带缓存的版本，用例跑通。
2. **加记忆化**：把 `dfs` 改成 `memo[i]`，一行缓存，复杂度立刻降下来。**很多题到这步就可以交了。**
3. **改递推**：观察 `memo[i]` 依赖哪些下标，改写成 `for` 循环从小到大填表。

| DP 细分 | 题目 | 递推方向 |
| --- | --- | --- |
| 线性（爬楼梯型） | 70, 746, 198, 213 | 从左到右，只看前 1-2 个状态 |
| 线性（子序列型） | 300, 139, 152 | 从左到右，回看所有更小的下标 |
| 背包 | 416, 322, 518, 494 | 外层物品、内层容量（0-1 逆序，完全背包正序） |
| 双序列 | 1143, 72, 97, 115 | 二维表，`dp[i][j]` 对应两个字符串前缀 |
| 区间 | 312, 5, 647 | 按区间长度从小到大枚举 |

## 六、C++ 起步模板（先把这些背到不用想）

```cpp
// 1) 哈希表计数
unordered_map<int, int> cnt;
for (int x : nums) ++cnt[x];

// 2) 前缀和（子数组求和类题目）
vector<int> pre(n + 1, 0);
for (int i = 0; i < n; ++i) pre[i + 1] = pre[i] + nums[i];
// 区间 [l, r) 之和 = pre[r] - pre[l]

// 3) 双指针（有序数组）
int l = 0, r = n - 1;
while (l < r) { /* 根据条件 ++l 或 --r */ }

// 4) 滑动窗口（最长型）
int l = 0, best = 0;
for (int r = 0; r < n; ++r) {
    // 右端点入窗，更新统计
    while (/* 窗口非法 */) { /* 左端点出窗 */ ++l; }
    best = max(best, r - l + 1);
}

// 5) 二叉树递归
int dfs(TreeNode* root) {
    if (!root) return 0;
    int left = dfs(root->left), right = dfs(root->right);
    return 1 + max(left, right);
}

// 6) 网格 DFS（岛屿类）
void dfs(vector<vector<char>>& g, int i, int j) {
    if (i < 0 || j < 0 || i >= g.size() || j >= g[0].size() || g[i][j] != '1') return;
    g[i][j] = '0';
    dfs(g, i + 1, j); dfs(g, i - 1, j); dfs(g, i, j + 1); dfs(g, i, j - 1);
}

// 7) 回溯模板
void backtrack(/* 状态 */) {
    if (/* 到达终点 */) { res.push_back(path); return; }
    for (/* 每个候选 */) {
        /* 选择 */  path.push_back(x);
        backtrack(/* 新状态 */);
        /* 撤销 */  path.pop_back();
    }
}

// 8) 二分查找（闭区间写法，记住它就行）
int lo = 0, hi = n - 1;
while (lo <= hi) {
    int mid = lo + (hi - lo) / 2;
    if (ok(mid)) hi = mid - 1; else lo = mid + 1;
}
// 答案 = lo
```

## 七、执行纪律（决定成败的部分）

1. **限时 35 分钟**，到点必看题解。磨 2 小时做出一题，不如 35 分钟学明白一题 + 第二天盲写一遍。
2. **看完题解必须盲写**。看着解析敲代码等于抄写，抄写不会长肌肉记忆。
3. **错题本只用一列**：记录「卡在哪一步」。例如「没想到用单调栈」「DP 状态定义错了，应该按长度而不是下标」。
4. **间隔复习**：标记为「看了解析才会」的题，在 1 天后、3 天后、7 天后各盲写一次（写不出来就重新计时）。复习日统一处理。
5. **不允许跳主题**。哪怕数组题做得再顺，也按第五节的顺序推进；主题内如果某题连续 2 次盲写失败，标记「重刷」并移到最后一周。
6. **Daily 优先于进度**。如果某天只有 20 分钟，就只做复习，不开始新题——半途而废的新题是负收益。
